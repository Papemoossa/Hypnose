Clé de secours (séquestre)

Une paire de clés RSA-2048 est créée pour votre étude. La partie publique est incluse dans l'application des participantes ; la partie privée reste ici, chiffrée par votre phrase de passe. Elle seule permet de rouvrir les données d'une participante ayant perdu son code.

Aucune clé

Sauvegardez ce fichier hors de votre ordinateur (clé USB, coffre). Sans lui et sans votre phrase de passe, aucune donnée de participante n'est récupérable.

Paramètres de protection
Transmission automatique des données (Supabase)

Les données partent déjà chiffrées avec votre clé publique : le serveur ne sert que de boîte aux lettres et ne peut rien lire. La clé « anonyme » ci-dessous est publique par nature ; la règle de sécurité SQL ne lui accorde que le droit d'insérer, jamais de lire.


  


  

    
Ce que fait l'application distribuée

    
    
      
  • Aucune requête réseau n'est possible : la politique de sécurité du contenu bloque toute connexion sortante (connect-src 'none').
    • 
      
  • Les données locales sont chiffrées en AES-256-GCM ; la clé est dérivée du code participante par PBKDF2-SHA256.
    • 
      
  • Le code d'accès n'est stocké nulle part, ni en clair ni sous forme réversible.
    • 
      
  • Verrouillage automatique après inactivité ; ralentissement exponentiel après tentatives erronées.
    • 
      
  • Aucun code d'administration, aucune clé privée, aucun identifiant T0 n'est inclus dans le fichier distribué.
    • 
      
  • Aucun cookie, aucun traceur, aucune bibliothèque externe.

Mise en ligne

    
Pour que les participantes puissent installer l'application sur leur téléphone et l'utiliser hors connexion, déposez le dossier complet (index.html, app.js, crypto.js, textes.js, config.js, sw.js, manifest.webmanifest, icons/) sur Netlify Drop ou GitHub Pages, en remplaçant textes.js et config.js par les fichiers générés ci-dessus.

    
N'y déposez jamais admin.html, RELAX-MIND-ADMIN.html, votre fichier de projet .rmproj ni votre clé .rmkey.
