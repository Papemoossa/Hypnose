RELAX MIND — GÉNÉRATEUR D'ICÔNES

Déposez votre logo, cadrez l'emblème (le visage et les feuilles, sans le texte), puis téléchargez le jeu d'icônes complet. Placez ensuite tous les fichiers obtenus dans le dossier icons/ de votre site.

Fichiers produits : icon-192.png · icon-512.png · icon-maskable-512.png · apple-touch-icon.png · favicon-32.png · emblem-256.png (fond transparent, pour l'en-tête) · logo.png (logo complet, écran d'accueil)
